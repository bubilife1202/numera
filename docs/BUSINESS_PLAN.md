# 수학 학습형 RPG 게임 "MathQuest (가칭)" 사업 기획서

**작성자**: Jules (30년차 프로그래머, PM, 개발자)
**작성일**: 2024년 5월 21일
**버전**: 1.2 (수정: 메이플스토리 스타일 강화 + 무중단 무비용 서버)

---

## 1. 개요 (Executive Summary)

### 1.1. 비전 (Vision)
"게임을 해도 공부가 된다"는 부모님의 니즈와 "메이플스토리처럼 재미있는 게임을 하고 싶다"는 아이들의 니즈를 동시에 충족시키는, 에듀테크(Edu-Tech)와 게이미피케이션(Gamification)이 결합된 최고의 수학 학습 플랫폼을 구축한다.

### 1.2. 목표 (Mission)
정통 2D 횡스크롤 액션 RPG (Side-Scrolling Action RPG) 장르를 채택하여, 타격감과 조작의 재미를 극대화한다. 웹 기술 기반으로 개발하여 PC와 모바일 어디서든 접근 가능한 크로스 플랫폼 환경을 제공하며, **Serverless 아키텍처**를 통해 고정 비용을 0원으로 만든다.

---

## 2. 시장 분석 및 타겟 (Market Analysis & Target)

### 2.1. 타겟 오디언스 (Target Audience)
1.  **핵심 사용자 (User)**: 초등학교 고학년 ~ 중학교 3학년 (10세 ~ 16세).
    *   2D 도트 감성의 아기자기한 캐릭터와 화려한 스킬 이펙트를 선호함.
    *   단순 클릭/터치가 아닌 직접적인 조작(점프, 이동, 공격)을 원함.
2.  **핵심 구매자 (Buyer)**: 학부모 (30대 후반 ~ 40대).
    *   자녀의 스마트폰 사용 시간을 걱정함.
    *   학습 효과가 증명된다면 유료 결제 의사가 높음.

### 2.2. 기존 시장의 문제점
*   기존 수학 게임은 정적인 퀴즈쇼 방식이라 '액션성'이 결여됨.
*   공부 느낌이 너무 강해 아이들이 "게임"으로 인식하지 않음.

## 3. 서비스 상세 기획 (Product Description)

### 3.1. 게임 컨셉: "판타지 수학 대륙 - 매쓰 아일랜드"
*   **장르**: **2D 횡스크롤 액션 RPG (Casual Side-Scrolling Action RPG)**.
    *   명확한 레퍼런스: **메이플스토리 (MapleStory)**.
    *   점프와 사다리 타기, 포탈 이동 등 플랫폼 게임의 요소 적극 도입.
*   **아트 스타일**: 친근하고 귀여운 2D 도트(Pixel Art) 또는 깔끔한 벡터 그래픽. 3등신 캐릭터.
*   **세계관**: '숫자의 에르다'로 이루어진 평화로운 매쓰 아일랜드에 '오류(Bug)' 몬스터들이 출몰. 플레이어는 이를 바로잡는 모험가가 됨.

### 3.2. 핵심 게임 메카닉 (Core Mechanics) - "액션과 수학의 결합"
1.  **전투 시스템 (Math Combat System)**
    *   **실시간 액션 + 퀵 매쓰**: 몬스터에게 스킬을 사용하면 화면 중앙에 짧은 수식이 팝업됨. (예: `7 x 8 = ?`)
    *   **데미지 스킨**: 정답을 입력하면 화려한 폰트로 데미지 숫자가 몬스터 위로 튀어 오름 (메이플스토리 시그니처 연출).
    *   **콤보 시스템**: 연속 정답 시 '피버 타임(Fever Time)' 발동, 배경 음악이 빨라지며 경험치 2배.
    *   **보스 레이드**: 거대한 보스 몬스터의 패턴(바닥 장판, 전체 공격)을 점프로 피하면서, 복잡한 응용 문제(약점)를 공략.

2.  **성장 시스템 (Progression)**
    *   **전직 시스템 (Job Advancement)**:
        *   레벨 10 달성 시 1차 전직.
        *   **검사 (기하학)**: 도형의 힘을 실은 검기 발사 (범위 공격).
        *   **매지션 (대수학)**: 방정식 주문을 외워 원거리 마법 구사.
        *   **로그 (확률)**: 주사위를 던져 랜덤 데미지 및 크리티컬 공격.
    *   **장비 및 코디**: 수학 도구(자, 컴퍼스)를 무기로 사용하며, 모자/옷/망토 등 다양한 치장 아이템으로 캐릭터 꾸미기(코디) 가능.

3.  **마을 및 커뮤니티 (Town & Social)**
    *   **헤네시스 같은 광장**: 플레이어들이 모여 대화하고 쉴 수 있는 평화로운 마을 맵 제공.
    *   **비동기 고스트**: 실시간 동기화 비용 절감을 위해, 마을에 보이는 다른 유저는 최근 접속한 유저의 '데이터(Ghost)'로 표현. 클릭 시 방명록 남기기 가능.

### 3.3. 학습 관리 시스템 (LMS for Parents)
*   학부모용 앱에서는 게임 내 '길라잡이' NPC가 되어 자녀에게 퀘스트(오늘의 학습 목표)를 부여하고 보상을 줄 수 있음.

## 4. 기술적 구현 방안 (Technical Architecture) - Zero Cost Strategy

"메이플스토리 같은 2D 액션"과 "서버 비용 0원"을 동시에 달성하기 위한 최적의 기술 스택.

### 4.1. 프론트엔드 (Engine & Hosting)
*   **엔진**: **Phaser 3** (가장 강력한 HTML5 2D 게임 엔진).
    *   메이플스토리와 유사한 물리 엔진(Arcade Physics) 내장: 점프, 중력, 충돌 처리 완벽 지원.
    *   타일맵(Tilemap) 지원으로 횡스크롤 맵 제작 용이.
*   **호스팅**: **GitHub Pages** (무료, 트래픽 제한 넉넉함).
*   **앱 패키징**: PWA (Progressive Web App). 아이폰/안드로이드 모두 설치 없이 웹 브라우저에서 "홈 화면에 추가"만으로 앱처럼 실행.

### 4.2. 백엔드 및 데이터베이스 (Serverless)
*   **플랫폼**: **Firebase (Spark Plan - 무료)**.
    *   **Auth**: 구글 로그인 연동.
    *   **Firestore**: 유저 세이브 파일(레벨, 아이템, 퀘스트 정보) 저장. JSON 형태의 NoSQL이라 게임 데이터 저장에 적합.
    *   **Security Rules**: 서버 없이도 DB 접근 권한을 제어하여 해킹 방지.
*   **게임 로직**:
    *   대부분의 로직(이동, 전투, 문제 출제)은 클라이언트(브라우저)에서 처리.
    *   중요한 보상 지급 검증만 **Cloud Functions** (월 200만 회 무료)으로 처리.

### 4.3. 멀티플레이어 전략 (비용 절감)
*   **가상 멀티플레이**: 실시간 위치 동기화는 서버 비용이 발생하므로 배제하거나 최소화.
*   대신, 마을에 입장하면 DB에서 최근 접속자 목록을 가져와 **NPC처럼 돌아다니게 함**. (유저가 북적이는 느낌은 주되, 서버 부하는 0).
*   **채팅**: Firebase Realtime Database를 사용하여 구현 (텍스트 데이터는 용량이 작아 무료 티어로 충분).

## 5. 개발 로드맵 (Development Roadmap)

### Phase 1: 프로토타입 (1~2개월)
*   Phaser 3 기반 횡스크롤 물리 엔진 구현 (점프, 이동).
*   기본 공격 및 데미지 스킨(숫자 팝업) 구현.
*   GitHub Pages 배포.

### Phase 2: MVP (3~4개월)
*   1차 전직 시스템 (3개 직업) 및 스킬 구현.
*   초등 수학 문제 은행 알고리즘 탑재.
*   로그인 및 클라우드 세이브(Firebase).

### Phase 3: 정식 서비스 (5~6개월)
*   상점 및 인벤토리, 코디 시스템.
*   월드맵 확장 (마을 1개 + 사냥터 3개).
*   학부모 연동 기능.

---

## 6. 수익 모델 (Business Model)

1.  **코디 아이템 판매**: 능력치엔 영향 없지만 캐릭터를 예쁘게 꾸밀 수 있는 헤어, 성형, 옷 쿠폰 판매. (메이플스토리의 핵심 BM 차용)
2.  **펫 시스템**: 자동으로 떨어진 아이템(메소)을 주워주는 펫 판매.
3.  **광고 제거**: 광고 없이 부활하거나 경험치 버프를 받는 프리미엄 상품.

---

## 7. 결론 (Conclusion)

본 프로젝트는 **"웹으로 즐기는 메이플스토리"**를 지향하며, 서버비 0원이라는 제약 속에서도 Phaser 3 엔진과 Serverless 기술을 활용하여 높은 퀄리티의 2D 액션 RPG를 구현할 수 있다. 타격감 있는 수학 전투로 아이들을 사로잡고, 비용 효율적인 구조로 사업성을 확보한다.
